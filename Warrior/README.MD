# 🐉 World of Warcraft 3.3.5a (Wrath of the Lich King) Macro Collection

# Warrior Edition

# Hamstring/Disarm

```lua
#showtooltip
/cast [stance:1],[stance:3] Hamstring
/cast [stance:2] Disarm
```

# Charge, Intervene, Intercept

```lua
#showtooltip
/cast [help] Intervene
/cast [stance:1],[stance:2],[harm] Charge
/cast [stance:3] Intercept
```

# Overpower, Shield Bash, Pummel

```lua
#showtooltips
/cast [stance:1] Overpower
/cast [stance:2] Shield Bash
/cast [stance:3] Pummel
```

# Shattering Throw, Shield Wall, Recklessness

```lua
#showtooltip
/cast [stance:1] Shattering Throw
/cast [stance:2] Shield Wall
/cast [stance:3] Recklessness
```
